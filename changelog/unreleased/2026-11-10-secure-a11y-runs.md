- **A secure field sends no accessibility text runs, revealed or masked.** Its runs held the plaintext while revealed and one dot per character while masked, with each character's length, place and width, so a reader or any process with accessibility access could read the password or count it. The field keeps its password role, name, value-setting and replace actions, and its value stays unset. With no runs it no longer offers to set a text selection, and a reader can no longer move through it by character.
