- **A Markdown image is its own block from its first character, `Markdown::images` is asked only for an image's whole source, its text after it starts at its first word, and `find` matches its alt text.** While a stream is still inside an image (`![a ch`), the image already stands as its block, its alt text growing there, instead of showing in the line and then leaving it once its source arrives. Its source waits for its `)`, and an image with no source shows its alt text without asking, so the app is never asked for an empty source or for part of a URL. An image with an empty source (`![alt]()`) is a block too, as `markdown.css`'s `img { display: block }` makes one. An image inside an image's alt text is part of that alt text, as CommonMark has it: `![foo ![bar](/url)](/url2)` is one image of `/url2` with the alt text `foo bar`, and the inner source is never asked for. The paragraph after an image no longer starts with the space between them. `markdown::find` matches an image's alt text in its own block, and `Markdown::highlights` marks it while the alt text shows.
